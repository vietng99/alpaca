# Alpaca runbook kit

This folder is the Alpaca runbook kit, format {{FORMAT}}. To write a runbook, read `AGENTS.md`
in this folder and follow it. The same steps are the `/runbook-forge` skill in
`.claude/skills/runbook-forge/SKILL.md`; copy that folder into a repository's `.claude/skills/`
to use the skill there.

Do not edit the files of this kit. `check_runbook.py` is the checker our machine runs.
