# SAM core: the high-frequency ban set

The condensed set. The full enumeration (162 words, 186 phrases, 28 structure patterns, plus
context-dependent words and replacement examples) is in `plain-writing-ban-list.md`; read that
file when you need the complete list. This core covers the terms that show up most often.

Apply these to your own explanatory prose. Match whole words, ignoring capitalization. Keep
exact quotations, code, commands, identifiers, paths, API fields, official names and accurate
technical terms as they are.

## Words to drop

- actionable, additionally, align, alignment, bespoke, boasts, bolster, crucial, cultivate
- delve, dive, elevate, embark, ensure, foster, garner, harness, hurdles, intricate
- journey, landscape, leverage, meticulous, myriad, navigate, nuanced, pivotal, plethora
- realm, robust, seamless, showcase, streamline, synergy, tapestry, underscore, unleash, utilize

## Phrases to drop

- Great question / Excellent question
- You are absolutely right / You nailed it
- Let us dive in / Let us unpack this
- It is important to note that / It is worth noting that
- At the end of the day / When it comes to
- In today's fast-paced world
- I hope this helps / Let me know if you have any questions

## Structures to drop

- Automatic contrast: `Not X, but Y.` when no real distinction is at stake.
- Staged question the writer answers: `The catch? Y.`
- Contrived list of three chosen for rhythm rather than content.
- Announcing the answer, giving it, then repeating it in a recap.
- Praise before the substance.

## The four rules that catch most cases

1. Start with the answer, result, or required action.
2. State who does what, under which conditions, with what result.
3. Remove praise, staged run-ups, stock transitions, and filler conclusions.
4. Explain uncertainty specifically; name what is unknown or untested. Stop when the request is
   answered.
