# Concise-writing reference

Explain lite (complete sentences without filler), full (compact phrases), and ultra (shortest
unambiguous phrasing). The user can request a mode or say "normal mode" to stop. Preserve the
user's language, technical identifiers, negations, numerical values, and necessary context.

The bundled companions are caveman-commit, caveman-review, caveman-compress, caveman-stats,
and cavecrew. Read the selected sibling SKILL.md when requested. Modes are conversation
preferences; this bundle does not install global activation hooks or configuration files.
