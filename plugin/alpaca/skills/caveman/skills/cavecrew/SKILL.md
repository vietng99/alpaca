# Alpaca bounded delegation

Use the active operator's native agent tools. Supply the concrete objective, allowed files,
required evidence, and stopping condition in the task packet. Investigators read and return
file:line pointers. Builders edit the assigned files and report validation. Reviewers return
only actionable findings with location, impact, and fix. Keep independent tasks separate.

Use the parent model unless the owner selected a different model. Named presets such as
cavecrew-investigator are role descriptions, not installed tools. If delegation is unavailable,
perform the bounded work locally and disclose that an independent review did not occur.
