# Budget survival

A run never spends its account to the wall; it keeps a reserve so it can always resume.

## The rule

Spending every token on a pooled account leaves a dead window with nothing left to even resume. Budget survival keeps a reserve and a resumable posture, so a campaign stays alive across a limit rather than stranding itself past one.

## Instrument

The code is the mechanism; this leaf is the reason, so the two never drift. Enforced by
`alpaca/posture/` reserve accounting.
