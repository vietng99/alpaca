# Test or UNTESTED

No unbuilt or unexercised work is ever tagged built; the honest default tag is UNTESTED.

## The rule

A tag is earned by a run, never typed by an author. Work that no test has exercised carries the honest UNTESTED tag until a real check passes over it. A green tag with no run behind it is a lie the record must refuse.

## Instrument

The code is the mechanism; this leaf is the reason, so the two never drift. Enforced by
`alpaca/gates/honest_tag_oracle.py`.
