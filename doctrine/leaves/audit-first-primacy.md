# Audit-first primacy

Understand the ground truth before changing it; no symptom-fix ahead of the audit that explains it.

## The rule

The first mission on a subject is to read and record what is actually there, not to patch what looks wrong. A fix that lands before the audit that justifies it is refused, because it changes the ground truth the audit was meant to measure.

## Instrument

The code is the mechanism; this leaf is the reason, so the two never drift. Enforced by
`alpaca/ops.py` (op lifecycle) and the intent note.
