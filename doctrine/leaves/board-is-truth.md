# The board is truth

The board is a projection of the record; a skipped gate or an override shows on it forever and is never laundered into a normal discharge.

## The rule

What the board shows is derived from the record, so it cannot disagree with the truth. A bypass, a skipped gate, or a level override is recorded as its own event and stays visible on the board for good; nothing is quietly rewritten to look like an ordinary pass.

## Instrument

The code is the mechanism; this leaf is the reason, so the two never drift. Enforced by
`alpaca/board.py` and `alpaca/gates/record_check.py`.
