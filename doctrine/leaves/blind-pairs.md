# Blind pairs

Independence is engineered: a checker never sees the builder's narrative, so shared bias cannot pass unchallenged.

## The rule

A reviewer who reads the author's reasoning tends to re-confirm it. Blind pairing withholds the narrative so the second look is genuinely independent, which is the only way a shared wrong assumption is caught rather than echoed.

## Instrument

The code is the mechanism; this leaf is the reason, so the two never drift. Enforced by
the review-card flow in `alpaca/decisions.py`.
