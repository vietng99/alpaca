# Lessons write-gate

A lesson is admitted only through a gate with a shrink floor; the store grows on evidence, not on every thought.

## The rule

An unbounded lessons store fills with restatement. A write-gate admits a lesson only when it clears the floor that keeps the store lean, and retirement decays what no longer earns its place, so the memory stays load-bearing.

## Instrument

The code is the mechanism; this leaf is the reason, so the two never drift. Enforced by
`alpaca/retention.py`.
