# Intent is the done-bar

A task is done when its recorded intent is met with a proof pointer, not when the author feels finished.

## The rule

The intent note written when work starts is the bar the work is measured against. Done means that intent is discharged with a resolvable proof, so completion is a record fact anyone can check rather than a claim only the author can make.

## Instrument

The code is the mechanism; this leaf is the reason, so the two never drift. Enforced by
the intent note in `alpaca/ops.py` and `--proof` in `alpaca/cli.py`.
