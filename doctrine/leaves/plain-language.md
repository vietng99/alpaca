# Plain language

Shipped prose is plain: no ceremony words, no filler; the ban list is data and the check is one lint.

## The rule

A harness that hides behind ornate language is harder to audit. Plain-language keeps shipped prose direct, with a banned-words list carried as data and enforced by one lint shared by the hook, the door and the style verb. The preset is opt-in per project.

## Instrument

The code is the mechanism; this leaf is the reason, so the two never drift. Enforced by
`alpaca/gates/literal_guard.py` and `style/banned.txt`.
