# CORE-CARD: the always-load spine

Every agent, every role, every phase carries the invariant core set before the
router narrows anything. This card carries the binding one-liner of each CORE
leaf so the rule is always in context; open the full leaf when the rule bites.
A pointer card, never the authority: on any conflict the leaf wins.

Safety invariant: this card only ADDS a cheap always-loaded layer; it never
SUBTRACTS a rule. If a one-liner here and its leaf disagree, that is a defect in
this card, not a licence to act on the shorter text.

## The CORE leaves

- File as truth: Every claim, verdict and order lives in a schema'd file; a return message carries a pointer, never the load-bearing content. Open `doctrine/leaves/file-as-truth.md` when the rule bites.
- Provenance or die: Every assertion carries a resolvable evidence pointer; an unevidenced claim is discarded, never laundered. Open `doctrine/leaves/provenance-or-die.md` when the rule bites.
- Test or UNTESTED: No unbuilt or unexercised work is ever tagged built; the honest default tag is UNTESTED. Open `doctrine/leaves/test-or-UNTESTED.md` when the rule bites.
- Verification tags, not signatures: A verdict is a derived tag over a real run, not a human signature; a guard that cannot fail proves nothing. Open `doctrine/leaves/verification-tags.md` when the rule bites.
- Halt on drift: When the subject under check changes underfoot, the run halts rather than reporting a stale verdict. Open `doctrine/leaves/halt-on-drift.md` when the rule bites.
- Crash-only resume: No in-memory state is assumed to survive; the run resumes from the record and a resume pad, never from a live process. Open `doctrine/leaves/crash-only-resume.md` when the rule bites.
- Double dispatch guard: Two live sessions cannot silently run the same step; a claim on the record makes the collision visible. Open `doctrine/leaves/double-dispatch.md` when the rule bites.
- Movement, gate, pin, sentinel: The gated-phase spine: work moves, a gate adjudicates, a pin fixes the verdict, a sentinel guards it against drift. Open `doctrine/leaves/movement-gate-pin-sentinel.md` when the rule bites.
- Record over ceremony: The append-only record with proof pointers replaces the old signed-checklist gate; a mark is an event, never a signature. Open `doctrine/leaves/record-over-ceremony.md` when the rule bites.
- The board is truth: The board is a projection of the record; a skipped gate or an override shows on it forever and is never laundered into a normal discharge. Open `doctrine/leaves/board-is-truth.md` when the rule bites.
